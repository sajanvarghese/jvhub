# jvhub the online wholesale marketing platform
About the Project

This project is an online wholesale product selling platform designed for small wholesale agencies to distribute their products efficiently along their corresponding routes. It helps improve business operations by allowing wholesale agencies to increase profits and reduce the need for certain staff involved in order processing.

The platform has two types of users:

Admin: The managing team of the wholesale agency. Admins can view orders, add product details (prices, stock, etc.), manage delivery routes for each day, view customer details, and generate reports of marketing activities done through the platform.

Customer: Customers can browse products, place orders, and view their order details, including prices and delivery dates.Customers can only log in using their GST number, ensuring secure and verified access.

This platform is very useful for wholesale agencies, as it streamlines order management and enhances overall business efficiency. It is built using Django for the backend, HTML, CSS, and JavaScript for the frontend, and Supabase as the database.
